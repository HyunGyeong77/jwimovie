## 💡 프로젝트 소개
영화에 대한 정보와 검색 및 필터 기능을 통하여 원하는 영화를 찾을 수 있는 사이트입니다.

## ✅ 개발 기간
* 24.11.23 ~ 24.12.04

## ⚙️ 개발 환경
- 언어 : JSX / SCSS / TS
- 라이브러리 : React
- 도구 : VS Code / Git
- 배포 : Github Pages

## ✨ 주요 기능
- Interactive UI/UX
  * 스크롤 이벤트
  * 마우스 오버 & 클릭 애니메이션
  * 필터 및 검색 기능
